# M00 stage 5: Codex adversarial challenge (codex-cli 0.163.0, read-only, 27 Oct)

1. **P1 — [02-app1-reader-features.md:847](docs/superpowers/plans/2026-10-27-02-app1-reader-features.md:847): Local-image access can expand to `/`.** The common ancestor of an installed renderer under `/Applications` and a document under `/Users` is `/`. Combined with the unconditional `file:` image hook and Quick Look’s filesystem-wide read exception, hostile Markdown can request unrelated local images. **Smallest fix:** use the constrained scheme handler consistently; canonicalise paths, enforce the current document’s allowed roots, and remove the `/` fallback.

2. **P1 — [08-growth-engine.md:562](docs/superpowers/plans/2026-10-27-08-growth-engine.md:562): The waitlist rate limit is bypassable.** The zone rule protects `tegelapps.com`, while deployed `pages.dev` hostnames expose the same Function. A script supplies the expected `Origin`, leaves the honeypot empty, and repeatedly requests confirmation emails. Origin checking does not authenticate scripts. **Smallest fix:** reject unexpected request hostnames and enforce shared per-address cooldowns and global sending limits inside the handler.

3. **P1 — [05-release-readiness-launch.md:314](docs/superpowers/plans/2026-10-27-05-release-readiness-launch.md:314): New dispatch-only workflows are needed before they reach `main`.** `smoke.yml` is created on `m05-launch`, but the matrix must pass before that branch merges. The same trap affects `design-shots.yml`. GitHub requires manually dispatched workflows on the default branch. **Smallest fix:** bootstrap the reviewed workflow definitions onto `main`, then dispatch explicitly against the milestone ref. [GitHub documentation](https://docs.github.com/en/actions/how-tos/manage-workflow-runs/manually-run-a-workflow).

4. **P1 — [03-licensing-updates-release.md:62](docs/superpowers/plans/2026-10-27-03-licensing-updates-release.md:62): `envset` produces a file that later commands cannot source.** It writes literal values without quoting. The planned signing identity contains spaces and parentheses; `APPLE_DEVELOPER_ID_IDENTITY=Developer ID Application: … (…)` is invalid shell syntax. Subsequent deploy, sales and buyer-sync commands source that file. **Smallest fix:** use one consistent literal dotenv parser instead of sourcing it. A synthetic identity reproduced the syntax error.

5. **P1 — [03-licensing-updates-release.md:583](docs/superpowers/plans/2026-10-27-03-licensing-updates-release.md:583): Activation is not transactional.** Polar allocates a slot before Keychain persistence. If saving fails, retrying consumes the second slot. Concurrent activations or replacing a stored key can also orphan allocations. The wrong-product cleanup additionally discards failures with `try?`. **Smallest fix:** serialise licence mutations, avoid duplicate activation, roll back known allocations on persistence failure, and retain failed cleanup operations for retry.

6. **P1 — [08-growth-engine.md:859](docs/superpowers/plans/2026-10-27-08-growth-engine.md:859): The buyer-email legal basis is unproven under the reseller structure.** The spec makes Polar the contractual seller, then assumes those purchasers are Baksh Logistics B.V.’s customers for soft opt-in. If that assumption fails, the negative checkbox supplies no affirmative consent. **Smallest fix:** obtain explicit marketing consent naming Baksh Logistics B.V./Tegel, or establish the reseller-specific legal basis before enabling sends. [ACM’s customer exception](https://www.acm.nl/nl/telecom/zakelijk-abonnement-voor-bellen-en-internet/spam).

7. **P1 — [08-growth-engine.md:871](docs/superpowers/plans/2026-10-27-08-growth-engine.md:871): Refund suppression misses ordinary refunds.** The daily sync fetches orders created in the last three days. A refund on day ten changes an older order, so it never reaches `remove`; the buyer remains eligible for day-21 and cross-sell emails. Likewise, `skipped` does not remove existing membership. **Smallest fix:** reconcile changed orders across the refund window, persist objections, and suppress queued emails as well as group membership.

8. **P1 — [04-site-seo.md:835](docs/superpowers/plans/2026-10-27-04-site-seo.md:835): Dutch consumer pricing is incomplete.** Dutch pages advertise USD-only prices and defer the final VAT-inclusive amount to checkout. Avoiding fake “was” prices does not satisfy the separate requirement to show consumer prices in euros, including VAT and unavoidable costs. **Smallest fix:** define real EUR consumer prices, configure matching Polar prices/tax treatment, and test the Dutch offer against checkout. [ACM pricing requirements](https://www.acm.nl/nl/verkoop-aan-consumenten/consumenten-informeren/prijzen-vermelden).

9. **P1 — [08-growth-engine.md:591](docs/superpowers/plans/2026-10-27-08-growth-engine.md:591): The browser tool’s “nothing is uploaded” promise is false.** Its CSP permits same-origin images. Pasting `![diagram](/private-project-name/architecture.png)` sends that private path to Cloudflare; an image URL containing sensitive query parameters sends those too. `connect-src 'none'` does not stop image requests. **Smallest fix:** strip all fetch-capable content URLs except permitted embedded images, and test same-origin requests—not just the remote beacon fixture.

10. **P1 — [01-g0-renderer-quicklook.md:1218](docs/superpowers/plans/2026-10-27-01-g0-renderer-quicklook.md:1218): Quick Look’s deadline excludes blocking file access.** `TextFileLoader.load` runs before the renderer timeout. A FIFO named `trap.md` can block opening; stalled network storage can also exceed two seconds before rendering starts. **Smallest fix:** open nonblocking, verify the opened descriptor is a regular file, move I/O off the main actor, and apply the deadline to the entire preview operation.

11. **P1 — [01-g0-renderer-quicklook.md:1091](docs/superpowers/plans/2026-10-27-01-g0-renderer-quicklook.md:1091): The window’s 5 MB protection happens after whole-file loading.** `FileDocument` obtains `regularFileContents`, then passes that `Data` into the capped decoder. A multi-gigabyte Markdown file can exhaust memory before the cap helps; the loader’s 50 MB test exercises another path. **Smallest fix:** make document opening use bounded URL-based reads, and test the actual Finder/window path with a huge file.

12. **P1 — [02-app1-reader-features.md:907](docs/superpowers/plans/2026-10-27-02-app1-reader-features.md:907): Search cancellation defeats the debounce.** Cancelling `.task(id: query)` interrupts `Task.sleep`, but `try?` swallows cancellation and proceeds into `model.search()`. Rapid typing therefore launches obsolete detached scans; older results can overwrite newer ones. At 5,000 files, these scans can repeatedly read gigabytes. **Smallest fix:** return on cancellation, propagate cancellation through scanning, and reject results whose query generation is stale.

13. **P1 — [05-release-readiness-launch.md:336](docs/superpowers/plans/2026-10-27-05-release-readiness-launch.md:336): The RC Sparkle acceptance test cannot reach RC1.** RC1 is built with `--no-upload` and stored only in a private GitHub release. That flag explicitly creates neither appcast nor upload, yet R10 expects the earlier build’s feed to offer RC1. **Smallest fix:** provide a separate authenticated test feed and matching test builds, or change the test sequence so the target archive is actually advertised before R10 runs.

14. **P1 — [06-app2-data-reader.md:947](docs/superpowers/plans/2026-10-27-06-app2-data-reader.md:947): App 2’s release change leaves Markdown paths hardcoded.** Adding the `data)` case changes only scheme, filename and volume. Plan 03 still hardcodes `dist-release/markdown`, the `/markdown/` download prefix and `markdown/appcast.xml`. Shipping Data consequently writes into Markdown’s release namespace while Data expects `/data/appcast.xml`. **Smallest fix:** parameterise every output/feed/upload path by app and assert both apps’ publication destinations.

15. **P1 — [06-app2-data-reader.md:627](docs/superpowers/plans/2026-10-27-06-app2-data-reader.md:627): App 2 never receives the runtime update and refresh wiring.** The plan specifies Sparkle plist keys and a `LicenseManager`, but no retained updater controller, update command, or launch/daily validation loop equivalent to plan 03. Plist configuration alone does not start Sparkle. **Smallest fix:** explicitly reuse that startup wiring and require production-build activation, relaunch validation and an actual Data update before release.

16. **P1 — [07-post-launch-scale.md:980](docs/superpowers/plans/2026-10-27-07-post-launch-scale.md:980): New v2 activations lose their entitlement identity.** `activate` still returns only an activation ID. `StoredLicense.benefitID` is filled on validation, but a nil value causes validation to send the v1 benefit. A newly activated v2 key therefore gets 404, remains nil, and never gains `hasV2`. **Smallest fix:** return and persist the activation response’s benefit ID immediately; reserve the v1 fallback strictly for migrated legacy records.

17. **P1 — [06-app2-data-reader.md:498](docs/superpowers/plans/2026-10-27-06-app2-data-reader.md:498): Live reload can crash through a mapped file.** `RecordIndex` maps the live source with `.alwaysMapped`. If an agent truncates that file while indexing or paging reads the old mapping, access can raise `SIGBUS`; FSEvents notification arrives too late to make that safe. **Smallest fix:** use bounded descriptor reads for mutable files and rebuild offsets when the file changes. [Apple documents this crash condition](https://developer.apple.com/library/archive/documentation/FileManagement/Conceptual/FileSystemProgrammingGuide/PerformanceTips/PerformanceTips.html).

18. **P1 — [07-post-launch-scale.md:87](docs/superpowers/plans/2026-10-27-07-post-launch-scale.md:87): The kill path does not preserve perpetual licences.** It cancels development while keeping apps on sale, although all paid features depend on Polar succeeding at least every 30 days. Account closure, an incompatible API change or abandoned maintenance can disable every purchaser’s Pro features. **Smallest fix:** make shutdown include a signed offline entitlement or a final entitlement-preserving build, and stop new sales before abandoning required maintenance. Necessary updates remain a consumer obligation. [ACM guidance](https://www.acm.nl/nl/verkoop-aan-consumenten/klantenservice/garantie).

19. **P1 — [03-licensing-updates-release.md:62](docs/superpowers/plans/2026-10-27-03-licensing-updates-release.md:62): Credential updates temporarily expose the entire secrets file.** `envset` creates predictable `.env.tmp`, writes every credential, renames it, and only then applies mode 600. With an ordinary 022 umask, another local account can read the temporary file. **Smallest fix:** set `umask 077` before creation and use a securely created temporary file; never rely on chmod after writing.

20. **P2 — [03-licensing-updates-release.md:266](docs/superpowers/plans/2026-10-27-03-licensing-updates-release.md:266): Clock rollback makes grace unbounded.** Every negative elapsed interval grants Pro. After one activation, a user can block validation and repeatedly keep the clock behind `lastValidatedAt`, including after refund or portal deactivation. Preserving the timestamp does not prevent this. **Smallest fix:** track clock rollback explicitly and require online recovery after a bounded anomaly allowance.

21. **P2 — [03-licensing-updates-release.md:1062](docs/superpowers/plans/2026-10-27-03-licensing-updates-release.md:1062): Deleting public sandbox betas does not retire their free licences.** Anyone who downloaded a signed beta can keep purchasing sandbox keys with test cards. Removing DMGs and the feed does not disable installed copies; the planned long-lived CDN caching complicates removal further. **Smallest fix:** distribute sandbox builds privately, retire their sandbox entitlement after acceptance, and purge cached beta objects.

22. **P2 — [04-site-seo.md:722](docs/superpowers/plans/2026-10-27-04-site-seo.md:722): First-deploy checks can approve an incomplete imprint.** They require name, address and KvK, but omit the BV’s already-known VAT ID; its insertion remains in the W6 section. Thus the launch gate can pass while contradicting master H7’s first-deploy requirement. **Smallest fix:** move VAT inclusion into the initial imprint task and make it a mandatory deployment assertion. [Belastingdienst requirement](https://www.belastingdienst.nl/wps/wcm/connect/bldcontentnl/belastingdienst/zakelijk/btw/administratie_bijhouden/btw_nummer_vermelden_op_website/).

23. **P2 — [08-growth-engine.md:373](docs/superpowers/plans/2026-10-27-08-growth-engine.md:373): The acquisition arithmetic cannot deliver G2’s sales target.** The plan’s 10,000 impressions × 2–4% CTR × 1% purchase conversion yields **2–4 sales**, not 25. Twenty-five sales require approximately **62,500–125,000 impressions** at those rates. Yet the MIDDLE gate permits further feature/MAS work. **Smallest fix:** reconcile the funnel targets and require evidence of qualified traffic and purchases before expanding scope.

24. **P2 — [04-site-seo.md:946](docs/superpowers/plans/2026-10-27-04-site-seo.md:946): The paid differentiation is weaker than the comparison implies.** BUSINESS-PLAN.md:198 already acknowledges MacMD’s paper-sized output through Print, but the comparison reduces its PDF capability to “one continuous page.” Meanwhile Tegel gives away the primary “press Space/read agent Markdown” job. **Smallest fix:** compare actual Print/PDF results, disclose the workaround, and validate willingness to pay for folder mode or demonstrably better RTL output before committing to App 2.
